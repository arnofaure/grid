# Grid Studio

A 100% free, single-file modular layout grid web app — created for the love of design systems by [Arno Faure](https://arnofaure.com).

🔗 **[grid.arnofaure.com](https://grid.arnofaure.com)**

## Features

- Modular, diagonal, and golden-ratio (Phi) grid systems, in the spirit of Josef Müller-Brockmann's *Grid Systems in Graphic Design*
- Müller-Brockmann grid presets (8/20/32-field) as a starting point
- Asymmetric column/row widths, adjustable by dragging boundaries directly on the canvas
- Place, resize, and rotate images, text blocks, and shapes (square/circle/diamond), with element-to-element and grid snapping
- Image pan/zoom/rotate inside a fixed frame, independent of the frame's own rotation
- Linked text blocks — overflow threads into the next linked block, like InDesign
- Reusable text style presets
- Multi-select, align/distribute, group-drag, and keyboard nudge
- Multi-page documents, with reusable page templates
- Bleed support for print
- Export to PNG, SVG, or PDF (real, selectable text)
- Save/open projects as JSON
- Runs entirely in your browser — no account, no upload, no tracking
